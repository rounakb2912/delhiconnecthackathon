# 🚌 Real-Time Bus Traffic Model & Dynamic Journey Planner
### Delhi Transport Stack Hackathon 2026 — Problem Statement 01

An end-to-end intelligent traffic modeling engine and dynamic journey planner built on real-time and historical GPS/location telemetry data generated by Delhi's public bus fleet.

---

## 🌟 Key Architecture & Modules

### 1. Data Ingestion & Preprocessing Pipeline (`pipeline/` & `data/`)
- **Live Delhi Open Transit Data (OTD) Ingestion:** Connects directly to Delhi's official GTFS-RT feed (`/api/realtime/VehiclePositions.pb`) at `otd.delhi.gov.in` to ingest live DTC and DIMTS cluster bus telemetry.
- **High-Fidelity Synthetic Simulation:** Realistic fallback generator modeling 100 buses across 50 stops and 15 routes with rush hour slowing, GPS drift, and stop dwell times.
- **GPS Drift Removal & Outlier Filtering:** Discards invalid coordinates, excessive drift (>500m off network), and speeds >80 km/h.
- **Bus Stop Dwell Time Filtering (DBSCAN + Spatial Radius):** Separates passenger boarding/dwell time from true road congestion. Buses within 50m of designated bus stops moving <3 km/h undergo spatial clustering using **Scikit-Learn DBSCAN** to flag dwell states, ensuring stationary buses never distort traffic velocity metrics.

### 2. Traffic Modeling & Map Matching (`traffic/`)
- **Delhi Road Network:** 107 road segments covering Ring Road, Outer Ring Road, Vikas Marg, Mathura Road, Aurobindo Marg, GT Road, and NH-48 Expressway.
- **Map Matching:** Snaps raw GPS points to nearest road segments with orthogonal distance projections.
- **Dynamic Speed Derivation:** Aggregates moving buses per segment in real-time, computing congestion levels: `free_flow` (green), `moderate` (yellow), `heavy` (orange), and `severe` / `gridlock` (red).
- **Predictive ML Layer:** Gradient Boosting model (`TrafficPredictor`) forecasting segment congestion and delays 30–60 minutes ahead based on time-of-day, day-of-week, and historical velocity trends.

### 3. Journey Planner & Routing Engine (`routing/`)
- **Graph Representation:** Bidirectional **NetworkX** directed graph with proximate intersection nodes merged within 50m.
- **Dynamic Weight Updates:** Edge weights are dynamically calculated as `t = distance / real-time_speed`.
- **A\* Routing with Haversine Heuristic:** Calculates shortest travel-time routes considering live congestion, returning complete turn coordinates, ETA, traversed segments, and human-readable congestion breakdowns.
- **Click-to-Route:** Click anywhere on the map to set origin and destination — no dropdowns needed.
- **GeoJSON Export:** Ready for frontend GIS visualization.

### 4. High-Performance Unified Web Frontend (`static/index.html` & `server.py`)

- **Interactive Route Simulation Engine:** Click **"Simulate Journey"** to watch an animated bus marker travel smoothly along the planned route in real-time with an active simulation progress bar and telemetry HUD.
- **Lock-On Camera & Live Bus Tracking:** Click on any bus in the map or fleet table to enter lock-on mode: camera follows the bus in real-time with live speed, route, and heading HUD.
- **Smart Autocomplete Stop Search:** Intelligent search for origin and destination stops with instant filtering, serviced bus routes, and Delhi Metro line interchange connectivity tags (e.g. 🚇 Blue/Yellow Line).
- **Dual Theme Support:** One-click toggle between **Cyberpunk Command Center Dark Mode** and **Clean Daylight Transit Light Mode**.
- **Interactive Stop Arrival ETA Board:** Select any stop to inspect upcoming incoming buses within 7.5 km with countdown timers and status badges.
- **AI Congestion Time-Machine:** Slider previewing Delhi traffic conditions from `Now` to `+60 Mins` using Gradient Boosting predictions.
- **Fleet Bunching Dispatcher Rebalancer:** Interactive tool to resolve bus clumping with one-click headway hold dispatch orders.
- **Multi-Route Corridor Branching:** Side-by-side comparative analysis of parallel transit branches with active fleet counts, headways, and corridor tracks.
- **Bolo Delhi Voice Assistant:** Speech recognition route search with audio visualizer and speech-to-audio feedback.
- **Digital Commuter Transit Pass:** Printable DTC-styled commuter pass with QR code and fare summary.

### 5. Interactive Streamlit Dashboard (`frontend/` & `app.py`)

#### 🗺️ 2D Folium Map
- **Switchable Basemaps:** Dark Matter (command center), Clean Light, and OpenStreetMap — toggle instantly.
- **Live Congestion Heatmap** (`folium.plugins.HeatMap`) with green→red gradient.
- **Color-Coded Road Segments:** Polylines colored by congestion level with speed tooltips.
- **Optimal Route Overlay:** Neon cyan (dark mode) or magenta (light mode) dashed route with origin/destination pins.
- **Live Bus Fleet Clustering:** `MarkerCluster` with speed-colored bus icons (🟢 fast, 🟡 moderate, 🔴 slow) and rich popup cards showing Bus ID, Route, Speed, and Status.
- **50 Major Bus Stop Markers:** Enhanced popups showing stop ID, coordinates, number of routes served, and bus line names.
- **500m Walkshed Radius:** Optional toggleable circles showing first-mile/last-mile pedestrian access zones.
- **Fullscreen Mode:** One-click button for presentation on projectors.
- **Click-to-Route:** Click on the map to set origin and destination without using dropdowns.

#### 🏙️ 3D Pydeck Visualization
- **3D Congestion Hexagon Columns:** Height and color encode congestion intensity — taller/redder = heavier traffic.
- **Live Bus Scatter Layer:** 3D scatterplot of active bus positions, color-coded by speed.
- **Origin-Destination Arc Flows:** 3D arcs showing major bus corridor traffic patterns (e.g., Rohini ↔ CP, Dwarka ↔ CP).
- **Bus Route Network Arcs:** Full visualization of all 15 route connections with cyan→orange directional gradient.

#### 📊 Commuter Dashboard
- **Telemetry Source Selector:** Toggle between 🟢 **Live Delhi OTD Feed** and 🟡 **Synthetic Simulation**.
- Route selector (bus stop dropdowns or custom coordinates).
- Live metrics: Distance, Dynamic ETA, Congestion Breakdown, Segments Traversed.
- Road segment traffic inspector table.
- Live active bus fleet tracker with Moving/Stopped counters.
- **🔮 ML Traffic Predictions:** 30-min and 60-min speed forecasts per road segment using Gradient Boosting.

## 🚀 Quickstart

### Option 1: Unified Full-Stack Mode (Recommended • Single Command • Port 8000)
Runs the FastAPI high-performance backend and the React 18 frontend together in a single command on **one single port**:

```bash
pip install -r requirements.txt
python server.py
```
*(Or double-click `run.bat` on Windows / run `./run.sh` on Linux/macOS)*

- 🌐 **Web Dashboard:** `http://localhost:8000`
- 📖 **Interactive API Docs (Swagger):** `http://localhost:8000/docs`
- ⚡ **Zero Setup & Zero Build Steps:** Runs out of the box with `static/index.html`. No separate Node/npm server or port proxying required.
- 🎯 **No CORS / Ephemeral Port Issues:** The React UI and FastAPI API share the exact same host and port.

---

### Option 2: Vite Dev Server Mode (For React Component Developers)
If you want live Hot Module Replacement (HMR) while editing JSX files:

```bash
# Terminal 1: Start FastAPI
python server.py

# Terminal 2: Start Vite Dev Server
cd frontend-react
npm install
npm run dev
```
Open `http://localhost:5173`.

---

### Option 3: Legacy Streamlit Dashboard
```bash
pip install -r requirements.txt
streamlit run app.py
```
Open `http://localhost:8501`.

### 3. Connecting to Official Live Delhi OTD Data
1. Visit the [Delhi Open Transit Data Portal (otd.delhi.gov.in)](https://otd.delhi.gov.in/) and request a free API key under **Real Time Data**.
2. In the app sidebar, switch **Telemetry Source** to **"🟢 Live Delhi OTD Feed"**.
3. Paste your key and click **"📡 Fetch Live Delhi Buses"**.
4. The dashboard will automatically fetch, clean, and model traffic based on live DTC & DIMTS bus positions!

## 🚀 Deploying to Render

This application is pre-configured for 1-click deployment on [Render](https://render.com/):

### Option A: Using the Render Blueprint (`render.yaml`)
1. Push your repository to GitHub.
2. Go to [Render Dashboard](https://dashboard.render.com/) and click **New +** → **Blueprint**.
3. Connect your repository (`delhiconnecthackathon`).
4. Render will automatically read `render.yaml` and configure the build command, start command, and port.
5. Click **Apply**. Your app will be live with a public HTTPS URL!

### Option B: Manual Web Service Setup on Render
1. Go to [Render Dashboard](https://dashboard.render.com/) → **New +** → **Web Service**.
2. Connect your GitHub repository.
3. Configure the following settings:
   - **Environment:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `streamlit run app.py --server.port $PORT --server.address 0.0.0.0 --server.headless true`
4. Under **Environment Variables**, add:
   - `PYTHON_VERSION`: `3.11.8`
5. Click **Create Web Service**.
